# Import and retranscription workflow

New media opens before transcription settings are chosen. The main screen keeps Settings and project opening; model and transcription language are in the empty transcript pane. Audio preparation builds reusable PCM/waveform data without loading speech models. Start transcription explicitly starts recognition. Existing unfinished jobs retain checkpoint resume behavior. Transcript import remains available in the transcript toolbar after opening media.

The top bar contains the editable project name and save/process status. Its meatballs menu contains Save, Open project, Save As, project folder, Close Project, processing pause/resume, and Export; Undo/Redo and Settings remain directly accessible. The redundant second project bar is removed. Video project cards use a saved first decoded frame; missing thumbnails are regenerated when an old project is opened. Audio projects keep their audio placeholder.

Select words or a blue timeline clip, then choose Retranscribe from the timeline meatballs menu (or its toolbar favorite if pinned). The dialog captures the source interval and offers an independent model and transcription language. The desktop job reads only that interval, splits long intervals into bounded checkpoints, and commits the replacement atomically after completion. Words outside the interval and manual cuts are retained. Selected transcript timestamps may change; original source media does not. Retrying an empty speech result clears only that interval. A very short selection may provide insufficient recognition context.

Validation: renderer and Electron type checks; checkpoint and progressive-result regression tests; range tests for exact PCM bounds, alternate model/language, pause/resume, atomic replacement, empty results and outside edits. Isolated desktop test imported example.mp4 with transcription disabled, saved its thumbnail, then explicitly transcribed with Tiny English. The selection dialog switched to Turbo for 1.26–1.48 seconds; all 44 outside words and manual cuts were unchanged.
